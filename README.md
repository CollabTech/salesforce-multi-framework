# Salesforce Multi-Framework — remote field-support PoC

Capability-validation proof of concept: can a field technician and a remote support
specialist work the same Salesforce case — camera/mic, two-way audio/video, screen share,
Salesforce Files, live image markup, 3D equipment — inside Salesforce on desktop and the
**physical Salesforce mobile app**, built as an internal **React UIBundle** shipped as an
**unlocked 2GP** package?

Backlog: Jira project **SMF** (16 stories, 54 acceptance-test case IDs). Every result is
evidence-based: PASS, FAIL, PARTIAL and BLOCKED are all valid, reviewed findings.

## Start here

- **Agents and contributors:** read [`AGENTS.md`](AGENTS.md) first (Claude Code loads it via `CLAUDE.md`).
- **What to test:** [`testing/README.md`](testing/README.md) — story ↔ case-ID index;
  shared personas/fixtures/DoD in [`testing/contract.json`](testing/contract.json).
- **Skills:** official Salesforce skills (pinned, installed on demand) + project `smf-*` skills in
  `.agents/skills/`; provenance in [`docs/provenance/official-skills.md`](docs/provenance/official-skills.md).

## First step after cloning

```sh
python3 scripts/bootstrap-skills.py      # Windows: py -3 scripts\bootstrap-skills.py
```

Installs the 28 pinned official Salesforce skills into `.agents/skills/` (not tracked) and
exposes every skill to Claude Code under `.claude/skills/`. Needs Python 3.8+, Node 18+
(`npx`), and network access to github.com and registry.npmjs.org.

## Checks (offline, no org access)

```sh
python3 scripts/verify-skills.py
python3 scripts/check-test-plan.py
python3 scripts/scan-public-content.py
python3 -m unittest discover -s scripts/tests
```
